СМАРТФОН AR ЖОБАСЫ

Бұл — телефон браузерінде жұмыс істеуге арналған MindAR + A-Frame демо-жобасы.
Оқулықтағы суретті камерамен танығанда, суреттегі смартфонның орнына интерактивті 3D смартфон шығады.

МАҢЫЗДЫ: targets.mind файлын бір рет жасау керек. Ол суреттен тану нүктелерін дайындайды.

1. https://hiukim.github.io/mind-ar-js-doc/tools/compile/ сайтына кіріңіз.
2. Осы қалтадағы target-image.png файлын жүктеңіз.
3. Start/Compile батырмасын басыңыз.
4. Дайын болған targets.mind файлын жүктеп алыңыз.
5. targets.mind файлын осы қалтаға, index.html файлының жанына көшіріңіз.
6. index.html және targets.mind екеуін GitHub репозиторийіне жүктеңіз.
7. GitHub репозиторийінде Settings → Pages → Deploy from a branch → main / root таңдаңыз.
8. Берілген GitHub Pages сілтемесін смартфонда ашыңыз. Камераға рұқсат беріңіз.

ТЕСТІЛЕУ:
- Сайтты телефонда ашыңыз (HTTPS қажет).
- Камераны оқулықтағы БҮТІН суретке бағыттаңыз.
- Смартфонның 3D моделі түпнұсқа суреттегі телефонның үстіне шығады.
- Айналдыру және үлкейту/кішірейту батырмаларын пайдалануға болады.

ЕСКЕРТУ:
- Модель — осы жобада жасалған жеңіл 3D смартфон прототипі.
- Камера суретті тануы үшін дәл осы target-image.png суретін пайдаланыңыз; суретті қиып не өзгертіп жібермеңіз.
- Бұл демо камераға және интернетке рұқсат қажет етеді.
